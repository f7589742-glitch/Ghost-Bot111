# بوابة تسجيل الدخول (بريد إلكتروني + كلمة مرور)

تشرح هذه الوثيقة كيفية إضافة حساب مزرعة إلى النظام: ماذا تكتب، ماذا يحدث داخل
النافذة، ومعنى كل رسالة خطأ وماذا تفعل عند ظهورها.

المرجع التقني المعتمد لبروتوكول Lilith:
`_archive/docs/LOGIN_PROTOCOL_SPEC.md` — أي تعديل على الدخول يجب أن يطابقه.

---

## 1) ماذا تكتب في النافذة

| الحقل | الشرح |
|---|---|
| البريد الإلكتروني (Game Account Email) | نفس البريد المسجَّل به في **Lilith Passport**. مثال: `farm4121+v2@hotmail.com` |
| كلمة المرور (Lilith Password) | كلمة مرور نفس الحساب في Lilith — **ليست** كلمة مرور داخل اللعبة ولا كلمة مرور حساب GhostBot |

ملاحظات:

-addition `+` في البريد (Lily Plus aliases) مدعومة وتعمل كحسابات مستقلة.
- زر 👁 بجانب كلمة المرور يعرضها أو يخفيها، ومفتاح `Enter` يبدأ الربط مباشرة.
- كلمة المرور لا تُحفظ في المتصفح؛ تُرسل مرة واحدة للخادم وتُخزَّن مشفّرة،
  وتُمسح من ذاكرة الصفحة فور نجاح الدخول.

---

## 2) ماذا يحدث بعد الضغط على «تسجيل ومزامنة الشخصيات»

1. يتحقق الخادم من الحقول (إن نقص أحدها تظهر رسالة عربية واضحة).
2. يسجّل الدخول لدى Lilith عبر بوابتهم الرسمية.
3. يطلب قائمة الشخصيات (governors) من Lilith.
4. يعرض لك الحكام المكتشفين في الخطوة الثانية مع خيار «تفعيل الشخصية المختارة`.

إما أن ينجح مباشرة، أو يطلب Lilith تحققًا أمنيًا (كابتشا) قبل المتابعة.

---

## 3) التحقق الأمني (الكابتشا)

- تُفتح **نافذة صغيرة (430×680)** فيها صفحة تحقق Lilith؛ حلّها هناك.
- النظام يفحص كل **6 ثوانٍ** تلقائيًا، وعند نجاح الحل يكمل الدخول وحده.
- أزرار مساعدة: «تحقق الآن»، «إعادة فتح النافذة»، و«إيقاف».
- **الحل اليدوي:** إذا انتهت مهلة الفحص التلقائي، انسخ `captchaId` من صفحة
  التحقق والصقه في خانة «رمز التحقق (captchaId)» ثم اضغط «تحقق بالرمز».

> سبب وجود الحل اليدوي: Lilith لا توفّر جسرًا يعمل داخل المتصفح العادي،
> لذلك لا يستطيع الموقع قراءة الرمز تلقائيًا (انظر المواصفة §4).

---

## 4) معنى رسائل الأخطاء ومعالجتها

| الرسالة | السبب الحقيقي | الحل |
|---|---|---|
| يرجى إدخال البريد الإلكتروني وكلمة المرور | حقل فارغ | أكمل الحقلين |
| كلمة المرور غير صحيحة | كلمة مرور Lilith خاطئة، أو البريد غير مسجَّل | تأكد من البيانات في صفحة Lilith الرسمية ثم أعد |
| تم رفض بيانات الدخول (1001) | خطأ تحقق من خوادم Lilith | انتظر دقيقة ثم أعد المحاولة |
| يتطلب الحساب تحققًا أمنيًا | كابتشا | افتح النافذة المصغرة وحلّها |
| تم تسجيل الدخول لكن Lilith لم يُرجع أي شخصية | الحساب غير مرتبط بممالك RoK | اربط حساب لعب اللعبة ثم أعد |
| تعذر الاتصال بخوادم Lilith | مشكلة شبكة | أعد المحاولة بعد قليل |

## 5) استخدام الواجهة البرمجية (اختياري)

```bash
curl -X POST https://ghost-bot-jade.vercel.app/api/accounts/sync \
  -H 'Content-Type: application/json' \
  -H 'x-user-id: <USER_ID>' \
  -d '{"email":"farm@example.com","password":"••••","bot_id":"bot-1"}'
```

الاستجابة عند النجاح تحتوي `characters[]` (قائمة الحكام).
عند الكابتشا تُعاد `status: "REQUIRES_VERIFICATION"` مع `captcha_url`.

للتحقق برمز يدوي:

```bash
curl -X POST https://ghost-bot-jade.vercel.app/api/accounts/verify-captcha \
  -H 'Content-Type: application/json' -H 'x-user-id: <USER_ID>' \
  -d '{"email":"...","password":"...","captcha_id":"<UUID>"}'
```

---

## 6) أمان الحساب

- كلمات المرور تُخزَّن مشفّرة على الخادم ولا تظهر في السجلات ولا في الواجهة.
- الربط مقيد بالمستخدم: لا يستطيع عميل آخر رؤية أو تعديل حساباتك.
- تُحفظ رموز الجلسة بصيغة `A-...` وتُستخدم للاتصال ببوابة اللعبة؛ عند انتهاء
  صلاحيتها يُعاد الربط تلقائيًا دون طلب كلمة المرور منك.
